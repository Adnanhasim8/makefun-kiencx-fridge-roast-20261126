# Roast the Smart Fridge — One Line, Best Laugh Wins

One line roasting the smart fridge: its touchscreen froze, and the irony is the only thing still running.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (one line, 80 characters, UTF-8, no network). To write elsewhere, set `MAKEFUN_OUTPUT_DIR`, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`.
